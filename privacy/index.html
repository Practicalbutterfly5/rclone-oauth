Privacy policy for rclone

Last updated: 29 September 2026

This policy covers the Google OAuth client named rclone, described on the application home page. It is a personal tool used by one person, its owner.

What data is accessed

With the owner's consent, the application accesses the owner's own Google Drive to create, read, update and delete files in folders the owner has chosen for backups and recordings. It uses the Google Drive API for this purpose only.

How the data is used

Files are uploaded from the owner's servers into the owner's Google Drive, and downloaded from it when the owner restores a backup. Nothing is analysed, aggregated or used for any other purpose.

Storage and sharing

The application does not collect, store or transmit any user data anywhere other than the owner's own Google Drive and the owner's own servers. No data is shared with, sold to or disclosed to any third party. There is no analytics, advertising or tracking of any kind.

Credentials

The OAuth token issued by Google is stored only on the owner's servers, in a configuration file readable by the owner alone. Access can be revoked at any time from the owner's Google Account under Security → Third-party apps with account access.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised with the owner via github.com/Practicalbutterfly5.
