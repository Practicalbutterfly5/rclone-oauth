rclone

Personal file sync client for Google Drive

This is the application home page for rclone, a personal, single-user Google OAuth client. It lets the open-source tool rclone copy the owner's own files to and from the owner's own Google Drive.

Who uses it

Only the owner of this page. The client is not offered to anyone else and has no other users.

Privacy

The application accesses only the owner's own Google Drive and shares nothing with anyone. Details are in the privacy policy.
